# من القاتل؟ — لعبة تحقيق جنائي

موقع لعبة تحقيق تفاعلية جاهز للنشر على GitHub Pages، مع نظام حسابات لاعبين مبني على Supabase.

## الملفات
- `index.html` واجهة الموقع.
- `styles.css` التصميم وخط Cairo.
- `app.js` منطق اللعبة.
- `auth.js` التسجيل/الدخول وحفظ تقدم اللاعب.
- `supabase-config.js` رابط ومفتاح Supabase العام.
- `database.sql` مخطط قاعدة البيانات وسياسات RLS.

## بيانات اللاعب
- الاسم.
- اسم المحقق Username.
- الدولة.
- البريد الإلكتروني وكلمة المرور عبر Supabase Auth.
- النقاط والرتبة والقضية الحالية وعدد القضايا المحلولة.

## الأمان
كلمات المرور لا يتم تخزينها داخل جدول اللاعبين؛ المصادقة تتم عبر Supabase Auth. جداول التطبيق مفعّل عليها Row Level Security.

> ملاحظة: النسخة الحالية تحفظ النقاط من الواجهة. قبل إطلاق مسابقات بجوائز حقيقية يجب نقل التحقق من الإجابات واحتساب النقاط إلى الخادم لمنع التلاعب من أدوات المطور.

## Supabase Integration
الموقع مربوط فعلياً بمشروع Supabase باسم `whoiskiller`.

- تسجيل وإنشاء الحسابات عبر Supabase Auth.
- جدول `player_profiles` لحفظ اسم المحقق والدولة والنقاط والرتبة والقضية الحالية.
- جدول `game_progress` لحفظ تقدم اللاعب في كل قضية.
- Row Level Security مفعّل لحماية بيانات التقدم.
- يتم استخدام Publishable Key فقط داخل الواجهة؛ لا يوجد Service Role Key داخل ملفات GitHub.

## GitHub Pages

## تحديث الواجهة
- صفحة تسجيل الدخول أصبحت الصفحة الرئيسية قبل بدء اللعبة.
- تصميم سينمائي فاخر بالأسود والذهبي/الأصفر.
- متجاوب مع الموبايل والتابلت والكمبيوتر.
- إظهار/إخفاء كلمة المرور.
- شاشة الدخول تختفي تلقائياً بعد نجاح المصادقة وتظهر واجهة اللعبة.


## إصلاح إنشاء الحساب
تم نقل إنشاء الحساب إلى Supabase Edge Function باسم `signup-player`.
الحساب يتم تأكيده تلقائياً من جهة الخادم، لذلك لا يعتمد إنشاء الحساب على بريد التأكيد الافتراضي المحدود في Supabase.
يوجد Rate Limiting على محاولات إنشاء الحساب للحماية من الإساءة.
